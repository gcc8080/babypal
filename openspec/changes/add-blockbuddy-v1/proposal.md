## Why

给快满 3 岁的儿子做一款离线、零广告、零内购的定制学习 App，作为生日礼物。

他当前已掌握 26 字母、0–100 数字、10 以内加法、一批象形汉字（山田土木/日月水火）与反义词、常见名词的中英双语。他最着迷的行为是**边看积木动画边用实体积木拼字母、数字、加法等式、汉字**。

现成的儿童 App 无法满足两点：一是内容起点太低（多数停在「数到 10」「认字母」），跟不上他的实际水平；二是普遍带广告、内购与数据上报。而这五类内容看似分散，其实共享同一个心智模型——**组合**：`3+2=5`、`C+A+T=CAT`、`木+木=林`、`红+黄=橙`。因此值得做的不是「五个小游戏拼盘」，而是**一套积木交互语法跑通五个内容域**：他在数字模块学会的拖拽/吸附/合体动作，走进汉字模块无需重新学习。

架构上要求内容与代码分离，使他 4–5 岁时只加 JSON 内容包即可升级，不改一行代码。

## What Changes

仓库当前是空壳（仅 openspec 脚手架 + `.fvmrc`），本次变更从零建立整个 Flutter 应用。

- **新建 Flutter 应用工程**，目标 Android + iOS，手机与平板自适应，**全局锁横屏**
- **新建积木引擎 `lib/core/block/`**——全项目复用的地基：网格吸附、拖拽、挤压回弹、`CustomPainter` 程序化表情、合体/分裂/群组。**「拖拽」与「点两下完成」双通道在引擎层就是一等公民**，不由各模块自行实现
- **新建五个内容模块**：数字（数数/位值/百格板）、加法（合体/分解/等式槽）、字母（A is for Apple 交互版/轮廓填充/大小写配对）、汉字（象形动画/部件加法/反义词跷跷板）、自由沙盒（无关卡无对错）
- **新建家长区**：家长门（长按 3 秒 + 两位数乘法）、逐条录音覆盖、每日时长上限、学习看板、素材署名页
- **新建生日彩蛋**：首启拼名字动画、`1+1+1=3` 蜡烛（麦克风吹气检测 + 点击降级）、家人相册
- **新建语音覆盖层**：家长录音写入文档目录后**无需重新打包即刻生效**，TTS 打底、真人语音增量替换
- **新建 JSON 内容包机制**（`assets/packs/*.json`）与两条离线内容流水线（TTS 批量生成、OpenMoji 图标抽取）
- **新建 CI**（仓库目前无任何 workflow）：analyze / test / Android debug 构建 / iOS 免签名构建
- **BREAKING（仅影响本仓库既有配置）**：`.fvmrc` 的 Flutter 由 `3.27.4` 升到 `3.44.8`；`.gitignore` 移除 `pubspec.lock` 忽略项，改为提交锁文件

## Capabilities

### New Capabilities

- `block-engine`: 积木交互语法的地基——网格吸附与宽容半径、拖拽与**点选双通道**、挤压回弹与表情动画、合体/分裂/群组。五个内容模块全部构建其上
- `audio-voice`: 音频总线（多短音效并发的音效池 + 语音队列）与**语音覆盖层**（文档目录录音 → assets 回落）
- `content-packs`: JSON 内容包格式、`schemaVersion` 兼容策略、四类内容模型的解析与校验
- `numbers-addition`: 位值拆解、百格板、合体加法、**反向分解**、等式槽
- `letters`: 字母名与音素、A is for Apple 交互版（多图全对）、字母轮廓填充、大小写配对、拼自己的名字
- `hanzi`: 象形字渐变动画、**部件加法**（复用加法模块的合体交互）、反义词跷跷板
- `sandbox`: 无关卡、无对错的自由拼搭台——决定这个 App 能玩两周还是两年
- `parent-zone`: 家长门、逐条录音覆盖、**基于墙钟的每日时长上限**、学习看板、素材署名
- `birthday`: 首启一次性生日彩蛋与可重播入口、蜡烛吹气检测及其降级路径、家人相册
- `child-safety-ux`: 3 岁交互红线（触控阈值、零文字、无挫败、误退出防护）与 App Store 儿童类目预先合规

### Modified Capabilities

无。`openspec/specs/` 目前为空，本变更引入的全部为新能力。

## Impact

**代码**：全新工程，无既有代码受影响。新增 `lib/`（core + modules + parent + birthday）、`assets/`（packs / audio / icons）、`tool/`（两条内容流水线）、`test/`、`.github/workflows/ci.yml`。

**既有配置**：`.fvmrc`（3.27.4 → 3.44.8）、`.gitignore`（取消忽略 `pubspec.lock`）。

**依赖**（均随 Flutter 3.44.8 走最新稳定版）：`flutter_riverpod ^3.3.2`、`flutter_soloud ^4.0.13`、`record ^7.1.1`、`shared_preferences ^2.5.5`、`path_provider ^2.1.6`、`wakelock_plus ^1.7.0`、`flutter_svg ^2.3.0`。`record 7.x` 要求 **Android minSdk 23**。

**刻意不引入**：游戏/物理引擎、Rive/Lottie、任何网络 / 分析 / 广告 SDK、完整 `intl` 本地化。理由见 `design.md`。

**平台**：Android 侧载无约束；iOS 在无开发者账号时只能用免费 personal team 签名，**证书 7 天过期**——详见 `design.md` 的风险取舍。

**法务红线**：教学法（立方体表数量、位值、Base-10 blocks / Cuisenaire 数棒）属公共领域，可自由借鉴；但角色形象、配色方案与「Numberblocks / 数字积木」名称受 BBC/Blue Zoo 保护，**必须原创造型与配色，且不得用作 App 名或角色名**。OpenMoji 图标为 CC BY-SA 4.0，**须署名并对图形衍生作品同协议共享**。
